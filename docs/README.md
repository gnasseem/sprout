# Sprout Story Workshop

A 29.4M parameter story model trained from scratch. Real float32 model inference runs in your browser, with no account or API key.

[Source and results](https://github.com/gnasseem/sprout) · [Model weights](https://huggingface.co/GeorgeCodesSometimes/sprout-instruct)

The first story downloads about 126 MB of weights plus the runtime. Instructions stay on your device. Sprout can repeat itself, lose details, and miss requested words or sentences.
